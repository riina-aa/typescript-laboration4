# Laboration4

Den här laborationen har introducerat ramverket Angular. Applikationen hämtar kursdata från en extern JSON-fil med hjälp av en Angular-service och HttpClient. Informationen presenteras i en tabell med kurskod, kursnamn och progression.

Användaren kan sortera kurserna alfabetiskt utifrån de tre kolumnerna samt filtrera kurserna genom att söka på kurskod eller kursnamn. Sortering och filtrering sker dynamiskt med hjälp av Angular Signals och databindning, utan att sidan behöver laddas om.
